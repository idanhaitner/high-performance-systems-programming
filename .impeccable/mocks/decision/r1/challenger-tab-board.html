Memory and pointers

In the last lesson, scanf needed &x, "the address of x". This lesson explains what that means.

Memory is a long row of numbered boxes

Imagine memory as a very long street. Each house is one byte, and each house has a number. That number is the byte's address.

Addresses are usually written in hexadecimal (base 16), with a 0x in front: 0x1000 is just the number 4096.
